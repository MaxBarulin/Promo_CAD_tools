# Адмиралтейские верфи — территория

Цифровая 3D-модель территории АО «Адмиралтейские верфи» (Санкт-Петербург, наб. реки Фонтанки, 203) с ближайшим окружением. Территория, все постройки, причалы, ковши и заводские мосты сняты с карты предприятия (`data/source/enterprise-map.png`).

Верфь занимает четыре участка (≈66 га): основную площадку между Фонтанкой и Пряжкой (стапели, ковш, главная проходная у площади Репина), Галерный остров в устье Фонтанки, западную часть Матисова острова с причалом у устья Мойки и Ново-Адмиралтейский остров. Вокруг — Большая Нева, Фонтанка, Пряжка, Мойка, Ново-Адмиралтейский и Адмиралтейский каналы, Коломна, жилая часть Матисова острова, Новая Голландия и противоположный берег Васильевского острова.

## Как открыть

**Просмотрщик.** Откройте `dist/index.html` в браузере (Chrome, Edge, Firefox, Safari). Сервер и интернет не нужны: three.js и данные встроены в файл. Модель строится в браузере за 1–2 секунды.

- левая кнопка мыши — вращение, правая — сдвиг, колесо — масштаб (к курсору);
- щелчок по зданию, крану, судну, мосту или забору открывает карточку: назначение, размеры, высота, этажность, площадь застройки, координаты;
- кнопки «Виды»: общий вид, план, главная проходная, стапели, Новое Адмиралтейство, Матисов остров, вид с Невы, со стороны Фонтанки; вид можно открыть по ссылке `index.html#slipways`;
- «Слои» включают и выключают группы объектов, «Вечернее освещение» зажигает окна;
- внизу справа — координаты курсора (WGS84 и локальные метры) и компас (щелчок — повернуть на север).

**Файлы для CAD и ГИС** лежат в `dist/`. Их же можно выгрузить кнопками «Экспорт» в просмотрщике.

| Файл | Формат | Чем открыть |
|---|---|---|
| `admiralty-shipyards.glb` | glTF 2.0, ≈18 МБ, 1271 объект в 9 слоях, материалы с русскими названиями, у объектов есть свойства (`extras`: id, назначение, высота, размеры) | Blender, 3ds Max, SketchUp (через плагин), Unreal/Unity, Windows 3D Viewer, онлайн-просмотрщики glTF |
| `admiralty-shipyards-plan.dxf` | DXF R12, метры, 19 слоёв (`BUILDINGS_SHIPYARD`, `FENCE`, `ROADS_CITY`, `SLIPWAYS`…). Контуры зданий — замкнутые полилинии с высотой (thickness), в 3D-виде это объёмы | AutoCAD, nanoCAD, КОМПАС-3D, BricsCAD, LibreCAD |
| `admiralty-shipyards.geojson` | GeoJSON, WGS84 | QGIS, geojson.io, JOSM, Яндекс/Google-карты (импорт слоя) |

GLB с полной детализацией всей застройки (около 30 МБ) собирается командой `npm run export -- --full`, а только верфь без города — `npm run export -- --no-context`.

## Система координат

Модель построена в локальной метрической системе: **x — на восток, y — на север, z — вверх**. Начало координат — центр площади Репина (59.91694° с. ш., 30.27948° в. д.). Перевод в WGS84 выполняют функции `toLatLon` и `fromLatLon` в `src/geo.js`. Уровень земли 0 м, вода −2,4 м. В three.js и GLB ось Y направлена вверх, а север соответствует −Z.

## Откуда геометрия и насколько она точна

**Верфь — по карте предприятия.** Скрипт `tools/trace_map.py` (Python, OpenCV) оцифровывает карту `data/source/enterprise-map.png` по цветам заливки: участки территории, 201 контур построек, акваторию, мосты, — и прокладывает внутризаводские проезды кратчайшими путями по свободным от зданий полосам. Результат — `src/data/map-trace.js` в пикселях карты; перевод в метры делает `src/data/mapdata.js`:

- **масштаб 1,514 м/пикс.** — из площади: вся территория на карте 292 тыс. пикс², при 67 га это 1,514 м/пикс. Проверка по отдельным участкам: Ново-Адмиралтейский остров 17,6 га (по данным ≈17 га), Галерный остров 10,8 га (≈10 га);
- **север — по стрелке на карте** (вправо с подъёмом ≈7°);
- **привязка** — юго-восточный угол основной площадки у главной проходной поставлен в 50 м к западу от центра площади Репина.

Контуры зданий и границы территории повторяют карту с точностью до толщины линии (±1,5–3 м в масштабе модели). **Назначение большинства зданий и все высоты — оценочные**: на карте нет подписей, поэтому корпуса классифицированы по площади и пропорциям, а названия даны только узнаваемым объектам (стапели, эллинги, проходная, заводоуправление). Такие объекты помечены в карточке как «Положение условное» (поле `approx`).

Карта изображает фоном «как воду» всё, что вне территории. Поэтому вода внутри «коридора» акватории (`WATER_CORRIDOR` в `tools/trace_map.py`) считается как «коридор минус территория», а суша, которую карта тоже залила фоном, вырезается отдельно (`LAND_CUTS` в `src/data/water.js`: Васильевский остров, квартал между Ново-Адмиралтейским каналом и Английской наб.). Ново-Адмиралтейский канал проходит вдоль юго-восточной стороны острова, ширина принята 30 м.

**Окружение — по открытым источникам.** Улицы, кварталы, Нева за пределами карты и противоположный берег привязаны с точностью около **±30–80 м**. Лоцманская ул. проводится вдоль ограды с отступом, чтобы тротуар не заходил на территорию.

Чтобы обновить модель по новой версии карты: замените `data/source/enterprise-map.png`, выполните `python3 tools/trace_map.py` (нужны `numpy` и `opencv-python-headless`), затем `npm run check`. Номера построек в `NAMED` (`src/data/shipyard.js`) — это индексы контуров в `map-trace.js`; при другой карте их нужно сверить.

### Уточнить окружение по OpenStreetMap

```bash
npm install
npm run osm:fetch      # скачать здания, воду, улицы, заборы в границах модели (Overpass API)
npm run build && npm run export
```

Скрипт сохраняет ответ в `data/osm/raw.json` и собирает слой уточнения `src/data/osm-overlay.js`. После этого:

- контуры и высоты зданий, вода, улицы и ограждения берутся из OSM;
- названия и описания цехов с карты предприятия переносятся на совпавшие OSM-контуры;
- стапели, краны, суда, доки и мосты остаются прежними.

Вернуться к данным карты: `npm run osm:convert -- --reset`.

> В облачном окружении, где собиралась модель, доступ к `overpass-api.de` закрыт сетевой политикой. Для импорта нужен обычный интернет или разрешённый домен `overpass-api.de` (другой сервер задаётся через `OVERPASS_URL`).

### Поправить данные вручную

Объекты описаны в файлах с комментариями:

- `src/data/shipyard.js` — назначение, высоты и оформление зданий с карты (`NAMED`, `classify`), стапели, краны, суда, доки, ворота (`GATES`), площадки;
- `src/data/water.js` — Нева за пределами карты, правый берег, реки и каналы, вырезы суши;
- `src/data/context.js` — улицы, площади, знаковые здания окружения;
- `tools/trace_map.py` — мосты, «коридор» акватории и опорные точки проездов (`ROADS`).

Здание окружения задаётся контуром (`rect(центрX, центрY, ширина, глубина, поворот°)` или списком точек), высотой, типом (`hall`, `office`, `historic`, `elling`…), цветом стен и типом кровли. Точку карты в метры переводит `px(xПикс, yПикс)` из `src/data/mapdata.js`. Окна, двери и карнизы строятся автоматически по типу. Чтобы сверить схему с космоснимком, откройте `dist/admiralty-shipyards.geojson` в geojson.io или QGIS поверх подложки, сдвиньте точки и перенесите исправленные координаты обратно (`fromLatLon(lat, lon)` переводит в метры модели).

После правок выполните `npm run check`: скрипт найдёт здания в воде, на проезжей и внутризаводских проездах и пересечения зданий.

## Команды

```bash
npm install            # зависимости: three, polygon-clipping, esbuild
npm run dev            # пересборка при изменениях + сервер http://localhost:8080
npm run build          # dist/index.html (+ dist/artifact.html для публикации)
npm run export         # dist/*.glb, *.dxf, *.geojson
npm run check          # проверка данных и статистика модели
npm test               # тест конвейера OSM на синтетических данных + проверка данных
npm run screenshots    # снимки всех видов в docs/img (нужен Playwright)
```

## Устройство проекта

```
src/
  geo.js              система координат, геометрия на плоскости
  data/               исходные данные: оцифровка карты и её привязка, вода, верфь, окружение, слой OSM
  model/              генерация 3D: рельеф и вода (булевы операции), дороги, здания с окнами,
                      ограда (автоматически по контуру), краны, суда и доки, мосты, рядовая застройка
  export/             DXF R12 и GeoJSON
  osm/convert.js      преобразование ответа Overpass в слой уточнения
  viewer/             интерфейс просмотрщика (three.js, OrbitControls, подписи CSS2D)
tools/trace_map.py    оцифровка карты предприятия (участки, здания, вода, мосты, проезды)
data/source/          карта предприятия — исходник геометрии верфи
scripts/              сборка, экспорт, проверка, импорт OSM, снимки экрана
test/                 синтетический ответ Overpass и тест конвейера
dist/                 готовые файлы
```

Модель полностью процедурная: один и тот же код строит сцену в браузере и в Node (для экспорта). Генерация детерминирована, поэтому при каждой сборке получается одна и та же застройка.
