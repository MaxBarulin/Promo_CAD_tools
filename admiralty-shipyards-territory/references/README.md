# Референсы: фото и схемы, по которым уточнялась модель

Папка по зданиям: имя папки — код объекта в модели (как в карточке и в `custom/custom.json`). В `_общее` — виды и генпланы, в `_не_сопоставлено` — снимки зданий, которые пока не привязаны к контурам.

**Что лежит в репозитории.** В git добавлены только снимки Wikimedia Commons под свободными лицензиями (автор и лицензия указаны ниже; лицензии требуют указывать автора и распространять производные на тех же условиях). Снимки и схемы с citywalls.ru, PastVu и фрагменты карты РГИС принадлежат их авторам: они лежат в этой папке локально, но в git не попадают (`references/.gitignore`), потому что репозиторий публичный. Ссылка на каждую публикацию есть в таблицах — снимок можно открыть или скачать заново.

**Как читать имена файлов.** `citywalls_<номер публикации>_схема|титул|фото_<номер снимка>.jpg` — снимок публикации `https://www.citywalls.ru/house<номер>.html`; «схема» — фрагмент схемы РГИС или старый план; `pastvu_<номер>.jpg` — `https://pastvu.com/p/<номер>`; `commons_….jpg` — Wikimedia Commons.
